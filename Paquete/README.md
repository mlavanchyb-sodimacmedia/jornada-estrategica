# Jornada Estratégica Sodimac Media 2027

Sitio estático de una página (`index.html`) con:
1. **Agenda** interactiva de la jornada (filtros, bloque en curso, reloj 10+5).
2. **Muro "Mi 2026 en una palabra"** para la moderadora (post-its, nube de palabras, proyección, exportar CSV).

## Publicar
- **GitHub Pages:** subir `index.html` al repo → Settings → Pages → Branch `main` / root.
- **Netlify:** arrastrar la carpeta en app.netlify.com/drop, o conectar el repo (sin build command, publish directory `/`).

Las palabras del muro se guardan en el navegador del computador de la moderadora (localStorage).
